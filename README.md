# Phanda (Shadow Executor)

### What is this?
The shadow executor interface and stewardship engine.

### Why does it exist?
To handle side-effects, cross-domain coordination, and external system integrations triggered by the core engine.

### How is it related to AXIONYX?
It provides the necessary background processing and execution guarantees for the immutable ledger.

### How do I run it?
```bash
npm install
npm run dev
```
