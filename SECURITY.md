# Security Policy

## Supported Versions

Security updates are applied to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the AXIONYX ecosystem, please DO NOT disclose it publicly on the issue tracker.

Instead, please send an email to the repository maintainer. 
We will review your report and provide a timeline for a fix or mitigation.
