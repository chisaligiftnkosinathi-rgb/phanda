# Identity Contract (v1.0.0)

## 1. Single Biological Mapping
Every physical human being must map to exactly ONE identity across the entire OS portfolio.

## 2. Infrastructure Ownership
Identity is exclusively owned, verified, and distributed by the **iPhande Platform**.

## 3. Application Delegation
Domain applications (Phanda, AXIONYX, iSebenza) do NOT own identity. They only hold **Permissions** and **Organization Memberships** linked to the canonical iPhande Identity ID.

## 4. Cross-System Revocation
If a human's identity trust status is revoked in iPhande, access is instantaneously and universally revoked across all domain applications.
