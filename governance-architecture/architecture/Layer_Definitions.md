# Epistemic Layer Definitions (v1.0.0)

## World A+ (Legality Lattice)
- **Role**: Structural execution constraints.
- **Responsibility**: Physics enforcement, preventing invalid state transitions before execution.
- **Limitation**: Does not evaluate meaning or truth; evaluates only structural legality.

## World A (Execution Kernel)
- **Role**: The reality engine.
- **Responsibility**: State mutations, database writes, physical changes.
- **Limitation**: Action only, devoid of interpretation.

## World B (Meaning Layer)
- **Role**: Human interpretation.
- **Responsibility**: Recording reflections, contextualizing execution.
- **Limitation**: Cannot alter execution history (World A).

## World C (Temporal Intelligence)
- **Role**: Pattern observation.
- **Responsibility**: Deriving intelligence over time from A and B.

## World C+ (Causal Memory Graph)
- **Role**: Causal history.
- **Responsibility**: Mapping the 'why' of events without altering truth.

## World C++ (Truth Tension Auditor)
- **Role**: Consistency checking.
- **Responsibility**: Detecting contradictions across interpretations and executions without forcing a resolution.

## World D (Evolution Engine)
- **Role**: Autonomous simulation.
- **Responsibility**: Proposing constraint changes based on instability.
- **Limitation**: Proposals are non-binding. No execution authority.

## World E (Governance Alignment)
- **Role**: Intent measurement.
- **Responsibility**: Tracing human intent drift vs. system reality.

## World F (Conscious Override)
- **Role**: Human arbitration boundary.
- **Responsibility**: Resolving system halt states (A+ blocks, E drift).
- **Limitation**: The system surfaces options; humans make the final sovereign choice.

## World G (Constitutional Lock Layer)
- **Role**: The Constitution.
- **Responsibility**: Defining immutable principles that protect the identity of the operating system.
