# Trust Lifecycle (v1.0.0)

Trust is a continuously calculated metric, inherently managed by World C++ (Truth Tension Auditor).

## 1. Initial State
- A new identity in iPhande starts with an "Unverified" trust status.

## 2. Accretion
- Successful workflows in Phanda (e.g., job completed, payment cleared) accrete trust.
- Verified documents (e.g., ID upload) accrete structural trust.

## 3. Tension (C++)
- Contradictions (e.g., identity logging in from impossible geographic locations simultaneously) generate Truth Tension.

## 4. Degradation
- High tension degrades the trust score.
- Below a critical constitutional threshold (Article X), the system halts execution (A+) and demands human arbitration (World F).
